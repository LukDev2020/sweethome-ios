## 2. 隐私与数据出境（数据存储在美国 us-central1）

| 市场 | 主要法规 | 出境 / 其他要点 | 需要做的 |
|---|---|---|---|
| 美国 | 各州隐私法（如 CCPA/CPRA，达门槛才适用）；COPPA | 13 岁以下用户受 COPPA 约束 | 隐私政策列明收集项；确认年龄门槛 |
| 加拿大 | PIPEDA；**魁北克 Law 25** | 魁北克：数据移出魁北克前须做隐私影响评估（PIA）；隐私政策需法文 | 做 PIA；法文隐私政策（已有法文界面） |
| 香港 | PDPO | 出境条款（第 33 条）未生效；需在收集声明中说明转移 | 收集声明写明数据存于美国 |
| 澳门 | 个人资料保护法（第 8/2005 号法律） | 转移到保护不足的地区需当事人明确同意或经主管机关许可 ⚠️ | 注册时取得「同意数据存于美国」的明确同意 |
| 台湾 | 个人资料保护法 | 一般允许出境，主管机关可限制 | 告知义务 |
| 新加坡 | PDPA | 传输限制义务：确保接收方提供相当保护（合同） | 与 Google Cloud 的数据处理条款存档 |
| 澳大利亚 | Privacy Act（APP 8） | 境外披露须确保符合 APP；含健康信息（医疗卡）不适用小企业豁免 | 隐私政策写明海外披露 |
| 新西兰 | Privacy Act 2020（IPP 12） | 跨境披露需相当保护或告知同意 | 告知 + 合同 |
| 马来西亚 | PDPA 2010（2024 修订） | 出境需目的地有类似法律或足够保障；数据保护官、泄露通报 ⚠️ | 指定 DPO（如达门槛） |
| 泰国 | PDPA | 目的地需有足够标准，否则需同意或例外 | 取得同意 |
| 菲律宾 | Data Privacy Act 2012 | 处理敏感个人信息（健康）超过 1000 人时需向 NPC 登记 ⚠️ | 达门槛前完成登记 |
| 日本 | 个人信息保护法（APPI）第 28 条 | 向境外第三方提供需同意，并告知对方国家制度；或对方采取同等措施 | 同意书中写明美国及其制度说明 |

**统一做法建议**：注册时增加一段「你的数据存储在美国（Google Cloud us-central1）」的单独同意（尚未做）。App 内隐私政策已加「跨境传输」章节（2026-10-31）；网站上的隐私政策需同步，并请法务按上表逐国确认。

## 3. 短信（Twilio）注册 ⚠️

SOS 升级会发短信给守护者和紧急联系人，各地对 A2P 短信有注册要求：
- 美国：长号码发 A2P 短信需完成 **10DLC 品牌与活动注册**，否则会被运营商拦截。
- 加拿大、澳大利亚、新西兰、新加坡、菲律宾、泰国、台湾、香港：多数要求注册字母发送者 ID 或使用本地号码；具体以 Twilio 各国家指南为准。
- 上线前用每个市场的真实号码测一遍 SOS 短信与语音外呼。

场景：妈妈已经被女儿守护，现在也想守护外婆

  1. 妈妈：设置 → 我也想守护家人（图 ⑥）。
  2. 外婆已装 App：外婆生成邀请码 → 妈妈输入 → 确认页「外婆邀请你成为她的守护者」→ 接受（图 ②）。
    外婆未装 App：妈妈发出「请让我守护你」链接 → 外婆安装后注册时自动选「我收到了邀请码」（图 ①）→ 确认页「陈秀兰想守护你，她将能看到……」→ 外婆同意。
  3. 关系建立 → 妈妈首页出现切换器「我 / 我守护的人 · 1」（图 ④）。
  4. 妈妈切到「我守护的人」照看外婆时，自己的 SOS、定位、跌倒检测照常运行（图 ⑤）。外婆求助时，无论妈妈在哪个视角都会收到提醒。
